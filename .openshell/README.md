# OpenShell in vongola — ORIGINATED PATTERN

Flag: no established OpenShell pattern existed anywhere in
Matt's estate when this was written (searched phlow, diver,
light-show, volta, and the dotfiles on 2026-10-10). This
directory is a minimal idiomatic equivalent, originated here,
and should be replaced wholesale when a canonical estate
pattern lands.

`openshell.json` declares the same contract the other agent
surfaces enforce: the spec is the source of truth, destructive
shell actions are denied, pushes require approval, and the
operator surfaces of the product itself (admin/MCP) stay behind
their token auth.
